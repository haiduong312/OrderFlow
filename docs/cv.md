# CV bullets and evidence

Suggested English bullets for a portfolio project; adapt wording to your own contribution. No production scale, real customers, delivery guarantee or unmeasured performance percentage is implied.

- Built a .NET 10 and React/TypeScript order-processing application with Identity cookie authentication, antiforgery protection, ownership-scoped APIs, responsive customer/Admin screens and isolated TanStack Query session caches.
- Implemented transactional PostgreSQL inventory reservations and idempotent checkout with exact response replay, ordered row locking, immutable price snapshots and append-only audit records, verified through real-database concurrency and failure tests.
- Developed simulated payment/refund recovery and RabbitMQ outbox/inbox workflows using durable operation identities, bounded retries, lease fencing and deduplicated local effects; integrated SignalR notification hints with durable HTTP catch-up.
- Delivered UTC financial reporting, optional OpenTelemetry instrumentation, a replicated local Docker Compose environment and GitHub Actions test/build definitions, with reproducible browser, failure and load-testing scripts.
